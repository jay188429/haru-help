# 회고 (M48)
- 잘된 것 (Keep) : 안내문 검색에 근거(문서 ID)를 붙여 답하게 한 것. 도구를 골라 쓰는 상담이 실제 사이트에서 재고 · 주문 · 안내문 질문에 모두 맞게 답했다. 보안 규칙을 시험 17개로 먼저 확인했고, 비용 안전장치(재시도 없음 · 인스턴스 2 · 정리 정책 1일)를 처음부터 걸었다.
- 막힌 것 (Problem) : 처음 배포 때 Eventarc 권한 때문에 함수 두 개가 실패해 몇 분 기다려 다시 배포했다. 호스팅이 한 번 「Site Not Found」로 떠서 다시 배포했다. 연습 상품 데이터가 운영 DB에 없어 재고 질문이 담당자에게 넘어갔다(에뮬레이터에서만 쓰던 함수라 놓쳤다). 모델이 없는 도구 이름을 만들어 화면에 보였다. 평가 세트가 작아 점수 차이를 믿기 어렵다.
- 다음에 바꿀 것 (Try) : 에뮬레이터에서만 되는 준비 작업(데이터 넣기)은 배포 점검표에 넣는다. 평가 세트를 늘리고 애매한 질문을 섞는다. 화면에 보이는 도구 이름은 실제 도구만 걸러서 보여 준다. 대화창에 붙여 넣은 API 키는 제출 후 교체한다.
